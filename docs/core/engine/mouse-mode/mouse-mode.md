## MouseMode

`MouseMode` enum class.

## Values

| MouseMode |
| :--- |
| NORMAL | Visible, moves freely (default). |
| HIDDEN | Hidden, moves freely. |
| CAPTURED | Hidden and locked to the window. |
| CONFINED | Visible but cannot leave the window. |
