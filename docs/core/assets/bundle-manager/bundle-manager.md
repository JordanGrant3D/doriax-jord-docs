## BundleManager

Registry for reusable **bundles** — prefab-like groups of entities spawned into any [**Scene**](../../scene/scene.md) at runtime. There is no API that loads a `.bundle` file directly at runtime: each `.bundle` file is converted into a factory function during export, and the exporter emits a `registerBundle` call wiring that factory to a numeric ID and a name (for example `tutorial/player`). Spawn an instance by name or ID with `createBundle` and remove it with `destroyBundle`. The CharacterController tutorial uses replay bundles such as `tutorial/player` to respawn the player rig and track loading progress.

## Properties

`BundleManager` is entirely static and exposes no public properties. Query the registry through `getBundleId`, `getBundleName`, `getBundleNames`, and `getBundleCount`.

## Constructors

`BundleManager` is entirely static and cannot be instantiated, so it exposes no public constructors. Register bundles with [**registerBundle**](bundle-manager-register-bundle.md), typically from the export-generated code.
