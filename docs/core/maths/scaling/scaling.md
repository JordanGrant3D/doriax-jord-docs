## Scaling

`Scaling` enum class.

## Values

| Scaling |
| :--- |
| FITWIDTH | Scale to fit width while maintaining aspect ratio. |
| FITHEIGHT | Scale to fit height while maintaining aspect ratio. |
| LETTERBOX | Scale to fit within the window with letterboxing. |
| CROP | Scale to fill the window, cropping excess. |
| STRETCH | Stretch to fill the window without maintaining aspect ratio. |
| NATIVE | Use the native resolution without scaling. |
