    Vector3

    Static Properties

    Type Property Description
    Vector3 ZERO Shorthand for writing Vector3(0, 0, 0).
    Vector3 UNIT_X Shorthand for writing Vector3(1, 0, 0).
    Vector3 UNIT_Y Shorthand for writing Vector3(0, 1, 0).
    Vector3 UNIT_Z Shorthand for writing Vector3(0, 0, 1).
    Vector3 UNIT_SCALE Shorthand for writing Vector3(1, 1, 1).

    Properties

    Type Property Description
    float x X component of the vector.
    float y Y component of the vector.
    float z Z component of the vector.

    Arguments Description
    Default constructor. Initializes components to zero.
    const float nx, const float ny, const float nz Constructs a vector with specified X, Y, and Z components.

    const int v[3] Constructs a vector from a 3-element integer array.

    Result Method Arguments Description
    float operator [] unsigned i Access component value by index (0 for x, 1 for y, 2 for z).
    float& operator [] unsigned i Access component reference by index (0 for x, 1 for y, 2 for z).

    bool operator == const Vector3& v Checks component-wise equality with another vector.
    bool operator != const Vector3& v Checks component-wise inequality with another vector.
    bool operator < const Vector3& v Returns true if all components are strictly less than target vector's components.
    bool operator > const Vector3& v Returns true if all components are strictly greater than target vector's components.
    Vector3 operator + const Vector3& v Performs component-wise addition.
    Vector3 operator - const Vector3& v Performs component-wise subtraction.
    Vector3 operator * const Vector3& v Performs component-wise multiplication.
    Vector3 operator * float f Performs scalar multiplication.
    Vector3 operator / float f Performs scalar division.
    Vector3 operator - Unary negation operator.
    Vector3& operator += const Vector3& v Adds vector in-place.
    Vector3& operator -= const Vector3& v Subtracts vector in-place.
    Vector3& operator *= float f Multiplies by scalar in-place.
    Vector3& operator /= float f Divides by scalar in-place.

    Methods

    Result Method Arguments Description
    float absDotProduct const Vector3& v Calculates the sum of absolute products of corresponding components.
    Vector3 crossProduct const Vector3& v Calculates the cross product vector perpendicular to both vectors.
    float distance const Vector3& rhs Calculates the Euclidean distance to another point.
    float dotProduct const Vector3& v Calculates the scalar dot product with another vector.
    bool isValid Checks that x, y, and z components are finite numbers.
    float length Calculates the magnitude (length) of the vector.
    Vector3 lerp const Vector3& target, float t Linearly interpolates between this vector and a target vector by factor t.
    void makeCeil const Vector3& v Updates each component to the component-wise maximum between this vector and v.
    void makeFloor const Vector3& v Updates each component to the component-wise minimum between this vector and v.
    Vector3 midPoint const Vector3& v Calculates the midpoint between this vector and another position vector.
    Vector3 moveTowards const Vector3& target, float maxDistanceDelta Moves the vector toward a target point by a maximum distance step.
    Vector3& normalize Normalizes the vector in-place to unit length and returns a reference to itself.
    Vector3 normalized Returns a normalized unit-length copy of this vector without modifying the original.
    float normalizeL Normalizes the vector in-place and returns its original magnitude.
    Vector3 perpendicular Calculates a normalized unit vector perpendicular (orthogonal) to this vector.
    Vector3 reflect const Vector3& normal Calculates the reflection vector off a surface defined by a normal vector.
    float squaredDistance const Vector3& rhs Calculates the squared distance to another point without square root overhead.
    float squaredLength Calculates the squared magnitude of the vector without performing a square root.
    std::string toString Returns a formatted string representation of the vector.
