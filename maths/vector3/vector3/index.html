    Vector3

    version: v0.7.1

    title: Vector3

    Static Properties

    Property Description
    ZERO Shorthand for writing Vector3(0, 0, 0).
    UNIT_X Shorthand for writing Vector3(1, 0, 0).
    UNIT_Y Shorthand for writing Vector3(0, 1, 0).
    UNIT_Z Shorthand for writing Vector3(0, 0, 1).
    UNIT_SCALE Shorthand for writing Vector3(1, 1, 1).

    Properties

    Property Description
    this[uint] Access the x, y, z components using [0], [1], [2] respectively.
    x X component of the vector.
    y Y component of the vector.
    z Z component of the vector.

    Methods

    Method Description
    isValid Checks that x, y, and z components are finite numbers.
    length Calculates the magnitude (length) of the vector.
    squaredLength Calculates the squared magnitude of the vector without performing a square root.
    dotProduct Calculates the scalar dot product with another vector.
    absDotProduct Calculates the sum of absolute products of corresponding components.
    distance Calculates the Euclidean distance to another point.
    squaredDistance Calculates the squared distance to another point without square root overhead.
    normalize Normalizes the vector in-place to unit length and returns a reference to itself.
    normalized Returns a normalized unit-length copy of this vector without modifying the original.
    normalizeL Normalizes the vector in-place and returns its original magnitude.
    crossProduct Calculates the cross product vector perpendicular to both vectors.
    midPoint Calculates the midpoint between this vector and another position vector.
    moveTowards Moves the vector toward a target point by a maximum distance step.
    lerp Linearly interpolates between this vector and a target vector by factor t.
    makeFloor Updates each component to the component-wise minimum between this vector and v.
    makeCeil Updates each component to the component-wise maximum between this vector and v.
    perpendicular Calculates a normalized unit vector perpendicular (orthogonal) to this vector.
    reflect Calculates the reflection vector off a surface defined by a normal vector.
